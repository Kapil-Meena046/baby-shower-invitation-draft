# Baby shower invitation

This is a mobile-first, single-page invitation. Open `index.html` in VS Code's Live Server or any browser to preview it. On a desktop, it stays in a centered phone-width layout; on a phone, it fills the screen.

The opening uses the `golden-palace.mp4` video from the Downloads folder. Tap the center play button to watch it; when it ends, the invitation page appears. Scroll to see the honored-to-have-you message, scratch-to-reveal date, calendar download, live countdown, and venue details in English and Hindi.

## Personalize it

Edit `event-details.js` in VS Code:

- Replace the parents' names, date, time, venue, English and Hindi address, and map URL. The venue is currently Kesar Bagh, Chittorgarh, Rajasthan.
- Keep `eventDate` in `YYYY-MM-DD` format. The countdown and revealed date use it.
- The welcome wording and headings live in `index.html` if you want to change those too.
- “Save the date” downloads a calendar invite file that guests can open to add the event to their calendar.

## Share it

To make a public link, upload this `outputs` folder to a static host such as GitHub Pages, Netlify, or Vercel. The host gives you a URL; share that URL in WhatsApp. Guests open the invitation directly in their phone browser. The link can't be publicly available until you publish it to a hosting service.

The date is set to November 15, 2026 based on your note. Please confirm the date and year before sharing.
